# 别让 AI 学会你

基于 NI myDAQ 实体操作台与玩家行为学习的二维 Boss 对战游戏课程项目。

玩家通过摇杆和按钮控制移动、攻击与闪避。系统从历史操作中学习玩家的闪避习惯，并调整 Boss 的招式选择；玩家通过改变打法和假动作尝试反制。LED 用于反馈技能冷却及 Boss 蓄力状态。

## 当前进度

已完成选题及开题报告，目前仓库保存项目方案和设备资料，尚未包含游戏实现代码。

## 拟用技术

- Python 和 Pygame：二维画面、交互与战斗逻辑。
- NI myDAQ、NI-DAQmx 驱动及 Python 接口：摇杆、按钮采集与灯光控制。
- scikit-learn：在 CPU 上运行的小型增量分类模型，用于预测玩家响应。

第一版限定一个竞技场和一个 Boss，提供固定策略与自适应策略两种模式。Boss 在蓄力时确定招式，不依据玩家后续按键临时改招，并保留清晰预警和躲避空间。
